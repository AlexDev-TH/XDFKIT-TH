# XDFKIT-TH

โปรแกรมแปลงไฟล์นิยามแมพ ECU สำหรับคนไทย ใช้งานผ่านหน้าต่าง ไม่ต้องพิมพ์คำสั่ง
แปลงไปมาได้ระหว่าง WinOLS KP, TunerPro XDF, A2L, DAMOS, JSON และ YAML
พร้อมดูค่าแมพจริงจากไฟล์ BIN และตรวจแก้แกนของไฟล์ KP

พัฒนาโดย **AlexDev-TH** ต่อยอดจากเอนจิน [xdfkit ของ nyetlabs](https://github.com/nyetlabs/xdfkit)

## ดาวน์โหลด

ไปที่หน้า [Releases](../../releases) แล้วโหลด `XDFKIT-TH.exe` มาเปิดได้เลย ไม่ต้องติดตั้ง

- ใช้ได้บน Windows 10 และ 11 แบบ 64 บิต
- ต้องมี WebView2 Runtime ซึ่ง Windows 11 มีมาให้แล้ว
- ไฟล์ยังไม่ได้เซ็นรับรอง ครั้งแรก Windows อาจขึ้นหน้าต่าง SmartScreen ให้กด "ข้อมูลเพิ่มเติม" แล้ว "เรียกใช้ต่อไป"

### ข้อความภาษาไทยในไฟล์ KP และ XDF

WinOLS และ TunerPro บน Windows ภาษาไทยเก็บข้อความไทยเป็นรหัส Windows-874
โปรแกรมนี้อ่านข้อความแบบนั้นออกมาเป็นภาษาไทยจริง และเขียนกลับในแบบเดียวกัน
ชื่อแมพและคำอธิบายภาษาไทยจึงข้ามระหว่าง KP กับ XDF ได้ครบทุกตัวอักษร
ส่วนไฟล์ JSON และ YAML จะได้ข้อความไทยแบบ UTF-8 ที่เปิดแก้ด้วยโปรแกรมแก้ข้อความทั่วไปได้

ข้อความที่ไม่ใช่ภาษาไทยจะถูกส่งผ่านเอนจินตามเดิมโดยไม่แตะต้อง

### ชื่อตารางระหว่าง WinOLS กับ TunerPro

WinOLS แสดงรายการแมพด้วยชื่อเต็ม ส่วน TunerPro แสดงด้วยชื่อหัวตารางอย่างเดียว โปรแกรมจึงจัดชื่อให้ตรงกับที่แต่ละโปรแกรมแสดง

- KP ไป XDF: หัวตารางใน TunerPro เป็น `รหัส: ชื่อเต็ม` เช่น `NZMSMN: untere Drehzahlgrenze für ZMS-Schutz` และหมวดของ WinOLS กลายเป็นหมวดใน TunerPro
- XDF ที่ทำใน TunerPro ไป KP: หัวตารางเป็นชื่อแมพใน WinOLS ส่วนคำอธิบายไปอยู่ในช่องหมายเหตุของแมพ
- แปลงกลับทางเดิมแล้วได้ชื่อ รหัส และคำอธิบายเหมือนต้นฉบับ

### ความถูกต้องของการแปลง

ชุดทดสอบในโฟลเดอร์ `app` อ่านไฟล์ XDF ที่แปลงได้ด้วยตัวอ่าน XML ธรรมดาที่ไม่เกี่ยวกับเอนจิน แล้วเทียบกับไฟล์ต้นทางทีละตารางทุกช่อง ได้แก่ ชื่อ คำอธิบาย หมวด แอดเดรส ขนาด จำนวนบิต เครื่องหมาย ลำดับไบต์ สูตร ทศนิยม หน่วย และแกน จากนั้นแปลงกลับเป็น KP แล้วเทียบกับต้นทางทีละตารางอีกรอบ ไฟล์ตัวอย่างที่ใช้ทดสอบมี 4,572 ตาราง

ตำแหน่งของเซลล์และจุดแกนตรวจด้วยกติกาของโปรแกรมต้นทางและปลายทางเอง คือกติกาคำนวณแอดเดรสของ WinOLS กับของ TunerPro ซึ่งอ่านมาจากตัวโปรแกรมทั้งสอง เมื่อแปลง KP เป็น XDF ทุกเซลล์และทุกจุดแกนต้องได้แอดเดรสเดียวกันจากทั้งสองกติกา ชุดไฟล์งานจริงที่ใช้ตรวจมี KP 256 ไฟล์ รวม 9,815 ตาราง และ 7,470 แกน ได้แอดเดรสตรงกันทั้งหมด รวมแกนที่มีไบต์เว้น 438 แกน ตารางที่มีไบต์เว้น 82 ตาราง และตารางแบบ 2D Inverse

ไฟล์ KP อ่านแล้วเขียนกลับได้ไบต์เดิม ตรวจกับไฟล์งานจริง 257 ไฟล์ ทั้งรูปแบบเดิม (เฮดเดอร์ 292) และรูปแบบของ WinOLS 5 (เฮดเดอร์ 503)

### สิ่งที่ควรรู้

- ไฟล์ต้นฉบับจะไม่ถูกเขียนทับ ถ้าปลายทางมีไฟล์ชื่อเดียวกันอยู่ โปรแกรมจะหยุดจนกว่าจะเปิดตัวเลือก "เขียนทับไฟล์ที่มีอยู่"
- แปลงเป็น XDF จะได้ไฟล์ `.meta.json` คู่กันมาด้วย เก็บไว้ข้างไฟล์ XDF จะแปลงกลับเป็น KP ได้เหมือนเดิม
- ไฟล์ KP อ่านได้ตั้งแต่เฮดเดอร์ 113, 116, 245, 292 จนถึง 503 และ 597 ของ WinOLS 5 ถ้าเจอรุ่นที่ยังอ่านไม่ได้ โปรแกรมจะแจ้งข้อความจากเอนจินให้เห็นตรง ๆ
- ไบต์เว้น (Skip bytes) ของ WinOLS อ่านจาก KP ได้ทั้งของแกนและของตาราง แล้วไปเป็นระยะเว้น (stride) ใน XDF ให้ TunerPro อ่านค่าตำแหน่งเดียวกัน
- เมื่อแปลงเป็น KP ไบต์เว้นของแกนเก็บได้เสมอ ส่วนไบต์เว้นของตาราง KP รูปแบบเดิมไม่มีที่เก็บ ต้องเลือกไฟล์ KP ที่บันทึกจาก WinOLS 5 เป็น "ไฟล์ KP ต้นแบบ" ไฟล์ที่ได้จะเป็นรูปแบบของ WinOLS 5 และเก็บไบต์เว้นครบ ถ้าไม่เลือก โปรแกรมจะบอกจำนวนตารางที่ได้รับผล
- ไฟล์ KP ที่บันทึกจาก WinOLS 5 มีข้อมูลไฟล์ ECU ติดอยู่ท้ายไฟล์ เมื่อใช้เป็นไฟล์ต้นแบบ ข้อมูลนั้นจะติดไปกับไฟล์ที่แปลงได้ และโปรแกรมจะแจ้งให้ทราบ
- ตารางที่เรียงเซลล์ย้อนกลับ หรือระยะท้ายแถวสั้นกว่าระยะระหว่างเซลล์ WinOLS ไม่มีรูปแบบรองรับ เมื่อแปลงเป็น KP โปรแกรมจะบอกจำนวนตารางที่ได้รับผล
- แมพแบบ 2D Inverse ของ KP แสดงและแปลงเป็น XDF ตามที่ WinOLS แสดง คือแต่ละแถวที่เก็บในไฟล์เป็นหนึ่งคอลัมน์ และแกน X กับแกน Y มีจำนวนจุดตรงกับตาราง ส่วนตาราง XDF ที่เรียงตามคอลัมน์จะเป็นแมพ 2D Inverse ใน KP
- ตาราง XDF ที่ใช้เซลล์ 1 บิตหรือเริ่มกลางไบต์ยังอ่านไม่ได้ โปรแกรมจะเตือนเป็นรายตาราง
- สูตรใน XDF ที่ไม่ใช่สูตรเส้นตรง เช่น สูตรยกกำลัง เก็บลง KP ไม่ได้ จะอ่านค่าเป็น X ตรง ๆ พร้อมคำเตือน
- รายการ XDFFLAG, XDFPATCH, XDFFUNCTION และ XDFCHECKSUM ไม่มีที่เก็บในรูปแบบอื่น จึงไม่ถูกแปลงไปด้วย
- ไฟล์นามสกุล .xdf ที่ไม่ใช่ XML ของ TunerPro อ่านไม่ได้
- การตรวจแกน KP รองรับ ECU ตระกูล Bosch ME7 และ Motronic M3/M5 ตามที่เอนจินรองรับ

## สร้างจากซอร์ส

ต้องมี Go 1.26.4 ขึ้นไป, Node.js 20.19 ขึ้นไป และ Wails CLI รุ่น 2

```powershell
go install github.com/wailsapp/wails/v2/cmd/wails@latest
cd app
powershell -File build.ps1
```

ได้ไฟล์ `app\build\bin\XDFKIT-TH.exe`

ทดสอบ

```powershell
go test ./...          # เอนจิน
cd app
go test ./...          # ส่วนเชื่อมหน้าต่างกับเอนจิน และข้อความภาษาไทย
```

เทสต์ในโฟลเดอร์ `app` ต้องมีโฟลเดอร์ `app\frontend\dist` ซึ่งได้มาจากการ build หนึ่งครั้ง

## สิ่งที่แก้จากเอนจินต้นฉบับ

อยู่ในโฟลเดอร์ `xdf/`, `kp/`, `model/`, `lint/` และ `mapcsv/` และมีเทสต์กำกับ กติกาเรื่องตำแหน่งเซลล์อ่านมาจากตัวโปรแกรม TunerPro RT v6 และ WinOLS 5 โดยตรง ส่วนลำดับฟิลด์ของแมพ แกน และโฟลเดอร์ในไฟล์ KP ทำตามส่วนอ่านเขียนไฟล์ของ WinOLS เอง รายละเอียดอยู่ใน `docs/kp-format.md`

ส่วน XDF

- ตำแหน่งเซลล์แบบเว้นช่วง เรียงย้อน และเรียงตามคอลัมน์ ทำตามกติกาของ TunerPro เดิมอ่านเป็นเซลล์ติดกันทั้งหมด
- ชนิดของแกนดูจาก embedinfo เดิมดูจากแอดเดรสที่ TunerPro ทิ้งค้างไว้ในแกน ทำให้อ่านแกนผิดที่
- ตารางที่อยู่ได้ถึงสามหมวด เขียนเป็นตารางเดียวในช่องหมวด A, B, C เดิมแตกเป็นตารางซ้ำหมวดละตัว
- แกนที่ลิงก์ไปยังตารางอื่น อ่านเป็นแกนจริงจากตารางนั้น เดิมอ่านเป็นลำดับ 0, 1, 2
- แกนที่พิมพ์ค่ากำกับไว้เอง เก็บค่าตามที่พิมพ์ เดิมค่าหายเหลือแต่ลำดับ
- สูตรของตาราง ใช้สูตรของทั้งตาราง เดิมหยิบสูตรเฉพาะเซลล์มาใช้แทนในบางไฟล์ และสูตรที่มีการขึ้นบรรทัดใหม่ถูกทิ้ง
- ชื่อหัวตาราง เขียนเต็มทั้งชื่อ เดิมตัดเหลือคำแรก
- จำนวนทศนิยม ใช้ตามไฟล์ต้นทาง เดิมถูกตัดลงตามค่าสูงสุดของชนิดข้อมูล
- จุดท้ายของแกนค่าคงที่ที่เป็นศูนย์ แสดงเป็นศูนย์ เดิมแสดงเป็นเลขลำดับ
- เตือนเมื่อเจอรูปแบบที่ยังเก็บไม่ได้ ได้แก่ เซลล์ที่ไม่ใช่ 8, 16, 32 บิต เซลล์ที่เริ่มกลางไบต์ และ BASEOFFSET

ส่วน KP

- ไบต์เว้นของแกน อ่านและเขียนได้ เดิมไม่ถูกอ่าน แกนที่มีไบต์เว้นจึงได้ค่าผิดเมื่อแปลงเป็น XDF
- ไบต์เว้นและไบต์เว้นท้ายแถวของตาราง อ่านได้จากไฟล์ของ WinOLS 5 และเขียนได้เมื่อไฟล์ต้นแบบเป็นรูปแบบนั้น
- แมพแบบ 2D Inverse เขียนเป็นตาราง XDF ที่เรียงตามคอลัมน์ เดิมเขียนตามลำดับที่เก็บ ทำให้แกน X และแกน Y มีจำนวนจุดสลับกัน
- แฟล็กค่าผกผัน (Reciprocal) ของแกน อ่านจากไบต์ที่ถูกต้อง เดิมไฟล์ที่มีแกนแบบนี้อ่านไม่ได้
- ไฟล์ของ WinOLS 5 (เฮดเดอร์ 503 และ 597) เขียนกลับได้ เดิมอ่านได้อย่างเดียว และโฟลเดอร์ที่มีสถานะมากกว่าหนึ่งไบต์อ่านไม่ได้
- ข้อความ `-`, `?` และ `%` ในไฟล์ของ WinOLS 5 อ่านได้ตามจริง เดิมกลายเป็นข้อความว่าง
- ตำแหน่งท้ายส่วนนิยามและขนาดข้อมูลไฟล์ ECU ในเฮดเดอร์ แยกเป็นสองฟิลด์ตามจริง
- ตัวตรวจแกนไม่แตะแกนและแมพที่มีไบต์เว้น เพราะกติกาตรวจอ่านค่าแบบเรียงติดกัน

## English

XDFKIT-TH is a Windows desktop app for converting ECU map definitions between WinOLS KP, TunerPro XDF, A2L, DAMOS, JSON and YAML. It shows map values read from a flash image, checks and fixes KP axes, merges definitions, and reads and writes Thai text (Windows-874) in KP and XDF files. The interface is in Thai and English, with dark and light themes.

It is built by AlexDev-TH on the [xdfkit](https://github.com/nyetlabs/xdfkit) engine by nyetlabs, with fixes to its XDF reader and writer (cell strides and column order as TunerPro places them, linked axes, fixed axis labels, table equations, whole titles, decimal places, several categories on one table) and to its KP reader and writer (record layouts taken from WinOLS's own serializer, skip bytes of axes and maps, 2D-inverse maps, WinOLS 5 packs written back), under the same licence, LGPL-3.0-or-later. Download `XDFKIT-TH.exe` from the Releases page, or build it with `app/build.ps1`.

# โปรแกรมหน้าต่าง XDFKIT-TH

โฟลเดอร์นี้คือโปรแกรมหน้าต่างของ XDFKIT-TH เป็นโมดูล Go แยกจากเอนจิน และเรียกเอนจินจากโฟลเดอร์แม่ผ่าน `replace` ใน `go.mod`

| ไฟล์ | หน้าที่ |
| --- | --- |
| `main.go` | เปิดหน้าต่างและตั้งค่า Wails |
| `app.go` | คำสั่งที่หน้าจอเรียกได้ เช่น ตรวจชนิดไฟล์ แปลง ตรวจแก้ KP รวมไฟล์ |
| `explore.go` | อ่านค่าแมพและจุดแกนจากไฟล์ BIN เพื่อแสดงผล |
| `thai.go` | อ่านและเขียนข้อความภาษาไทยแบบ Windows-874 ในไฟล์ KP และ XDF |
| `names.go` | จัดชื่อตารางให้ตรงกับที่ WinOLS และ TunerPro แสดง |
| `frontend/src/` | หน้าจอ เขียนด้วย React กับ TypeScript |
| `frontend/src/i18n/` | ข้อความภาษาไทยและอังกฤษ |
| `branding/` | โลโก้ แบนเนอร์ และ `make_assets.py` สำหรับสร้างไอคอนกับภาพที่ใช้ในหน้าจอ |

## คำสั่งที่ใช้บ่อย

```powershell
powershell -File build.ps1     # สร้าง build\bin\XDFKIT-TH.exe
go test ./...                  # ทดสอบส่วน Go
cd frontend; npx tsc --noEmit  # ตรวจชนิดข้อมูลของหน้าจอ
```

## เพิ่มข้อความหรือภาษา

ข้อความทุกคำอยู่ใน `frontend/src/i18n/th.ts` ซึ่งเป็นต้นแบบของคีย์ และ `en.ts` ต้องมีคีย์ครบเท่ากัน ถ้าขาดจะ build ไม่ผ่าน
